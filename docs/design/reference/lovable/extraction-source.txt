Design System — « Plus tard » (iOS Flutter Edition)

> Document technique extrait fidèlement du code source de l'application web (`src/styles.css`, `src/routes/__root.tsx`, `src/routes/index.tsx`, `src/lib/thoughts.ts`).
> Ne contient aucune estimation visuelle ni extrapolation arbitraire.

---

1. Vue d'ensemble & Philosophie visuelle

L'application suit une esthétique éditoriale épurée d'inspiration iOS haut de gamme :
- Fond chaud crémeux / sable (`--background`, `--device`), s'écartant du blanc froid natif.
- Typographie bivalente : empattements littéraires contemporains (Newsreader) pour la pensée et les titres ; linéale technique et lisible (Inter Tight) pour l'UI, boutons, métadonnées et navigation.
- Accentuation chromatique unique : une nuance de Lavande / Violet feutré (`--primary`) réservée aux actions principales, compteurs et raccourcis d'action.
- Formes douces & continues : rayons de courbure prononcés (`rounded-full`, `rounded-2xl`, squircle iOS).

5. Ombres & Élévation (Box Shadows)

5.1 Ombre de Carte (`--shadow-card` / classe `.shadow-card`)

Composée de deux couches superposées :
```css
/* Light mode */
box-shadow: 0 1px 2px oklch(0.2 0.02 60 / 4%), 0 8px 24px -12px oklch(0.2 0.02 60 / 10%);
```
Équivalent Flutter `BoxShadow` (Light) :
```dart
const cardShadow = [
  BoxShadow(
    offset: Offset(0, 1),
    blurRadius: 2,
    spreadRadius: 0,
    color: Color(0x0A1A1511), // 4% d'opacité
  ),
  BoxShadow(
    offset: Offset(0, 8),
    blurRadius: 24,
    spreadRadius: -12,
    color: Color(0x1A1A1511), // 10% d'opacité
  ),
];
```

En Dark Mode :
- Couche 1 intérieure : `inset 0 1px 0 rgba(255, 255, 255, 0.04)`
- Couche 2 diffuse : `0 8px 24px -12px rgba(0, 0, 0, 0.50)`

5.2 Ombre Portée Flottante (`--shadow-float` / classe `.shadow-float`)

Utilisée sur le Toast et sur le simulateur d'appareil :
```css
/* Light mode */
box-shadow: 0 20px 50px -20px oklch(0.4 0.1 295 / 35%);
```
Équivalent Flutter `BoxShadow` (Light) :
```dart
const floatShadow = [
  BoxShadow(
    offset: Offset(0, 20),
    blurRadius: 50,
    spreadRadius: -20,
    color: Color(0x59533E89), // Lavande sombre à 35% d'opacité
  ),
];
```

6. Composants & Spécifications Géométriques

6.1 Boutons

1. Bouton Principal « Déposer » :
   - Hauteur : `44px` (`h-11`).
   - Padding horizontal : `24px` (`px-6`).
   - Rayon : `rounded-full` (`BorderRadius.circular(999)`).
   - Fond : `bg-primary` (`#6F57AB`), au repos.
   - État désactivé (`disabled`) : `bg-secondary` (`#EEEAE5`), texte `Color(0x9977706B)`.
   - Interaction au toucher : `active:scale-95` (`scale(0.95)`).

2. Bouton de navigation retour (« Capturer ») :
   - Hauteur : `44px` (`h-11`).
   - Padding : gauche `4px` (`pl-1`), droite `12px` (`pr-3`).
   - Rayon : `rounded-full`.
   - Couleur texte & chevron : `text-primary` (`#6F57AB`).
   - Typographie : 16px, Regular/Medium.
   - Interaction : `active:opacity-60`.

3. Bouton Icône Boîte de Réception (Header Capture) :
   - Dimensions : carré `44px × 44px` (`size-11`).
   - Positionnement : marge négative `mr-[-8px]` (`-mr-2`) pour aligner l'axe de frappe tactile sur la marge droite.
   - Rayon : `rounded-full`.
   - Interaction : `active:scale-90 active:bg-secondary`.
   - Pastille badge (si `count > 0`) :
     - Position : `top: 6px`, `right: 4px`.
     - Hauteur : `18px`, largeur minimale `18px`.
     - Rayon : `rounded-full`.
     - Padding horizontal : `4px` (`px-1`).
     - Fond : `bg-primary`, texte 11px gras `text-primary-foreground`.

4. Bouton Raccourci Action dans Carte (Pilule) :
   - Hauteur : `28px` (`h-7`).
   - Padding : horizontal `12px` (`px-3`), gap entre texte et icône `6px` (`gap-1.5`).
   - Rayon : `rounded-full`.
   - Fond : `bg-primary-soft` (`#ECE7FF`).
   - Texte et flèche diagonale : `text-primary` (`#6F57AB`), 13px Medium.
   - Interaction : `active:scale-95`.

6.2 Checkbox de Validation (Tâche Terminée)

- Taille : `22px × 22px` (`size-[22px]`).
- Marge haute : `3px` (`mt-[3px]`) pour aligner optiquement le cercle avec la première ligne de texte en 18px.
- Bordure non cochée : `1.5px` continue, couleur `Color(0x6677706B)` (`border-muted-foreground/40`).
- État coché :
  - Disque plein lavande `bg-primary` en transition de zoom ressort (`scale: 0` vers `scale: 1`).
  - Coche blanche vectorielle : trait de `3.5px`, `StrokeCap.round`, `StrokeJoin.round`.

6.3 Champ de Saisie (Textarea de Capture)

- Fond : transparent (`bg-transparent`).
- Alignement : pleine largeur, suppression de redimensionnement (`resize-none`), sans bordure ni contour (`outline-none`).
- Hauteur de base : 4 lignes visibles (`rows={4}`).
- Curseur de frappe : teinté lavande (`caret-primary`).
- Raccourci clavier : `Enter` (sans Shift) ou `Cmd/Ctrl + Enter` déclenche directement l'enregistrement.

6.4 Carte de Pensée (`Card`)

- Conteneur : `rounded-2xl` (rayon 24px), fond `bg-card` (`#FFFDFB`), ombre `shadow-card`.
- Padding interne : `16px` (`p-4`).
- Disposition en ligne (`flex gap-3`) :
  - Colonne gauche : Bouton checkbox (22px).
  - Colonne centrale : Zone extensible (`min-w-0 flex-1`) contenant le texte de la pensée et la rangée métadonnées (badge + date espacés de `gap-2`).
  - Colonne droite : Bouton trois points `size-9` (36×36px), centré.

6.5 Toast / SnackBar

- Hauteur fixe : `56px` (`h-14`).
- Position : flottant au bas de l'écran, ancré à gauche et droite `left: 16px, right: 16px`, bas `max(safeAreaBottom, 20px)`.
- Rayon : `rounded-2xl` (24px).
- Fond : `bg-foreground` (`#1A1511` en light).
- Typographie : texte 15px en couleur inverse `#F9F6F2`.
- Bouton « Annuler » : hauteur `40px` (`h-10`), padding `px-4`, texte 15px SemiBold lavande douce (`#ECE7FF`).
- Durée de vie : 5000 ms avec bouton d'annulation, 2200 ms pour un simple feedback (« Copié »).

6.6 Feuilles Modales (Action Sheets)

Le design reproduit fidèlement la structure en deux blocs superposés d'iOS :
- Marge latérale : `8px` (`inset-x-2`).
- Marge basse : `max(safeAreaBottom, 8px)`.
- Bloc Actions supérieures :
  - Rayon : `rounded-2xl` (24px), fond `bg-popover`.
  - Séparateurs : `divide-y divide-border` (liseré 1px `#E1DDD8`).
  - En-tête : extrait de la pensée tronqué à 2 lignes (`line-clamp-2`), padding `px-5 py-3`, Newsreader 15px centré.
  - Rangées d'actions : hauteur `56px` (`h-14`), padding `px-5`, taille 17px. Effet de pression : `active:bg-secondary`.
  - Action destructrice (« Supprimer ») : texte `#D73337`.
- Bloc Inférieur (« Fermer ») :
  - Espacé de `8px` (`gap-2`) du premier bloc.
  - Hauteur : `56px` (`h-14`).
  - Rayon : `rounded-2xl` (24px), fond `bg-popover`.
  - Texte : 17px SemiBold centré.

enum SuggestionKind { phone, mail, calendar, reminders, web, maps }

class SuggestionRule {

  final String app;
  final RegExp words;

  const SuggestionRule({
    required this.kind,
    required this.label,
    required this.app,
    required this.words,
  });
}

// Nettoyage des diacritiques (accents) avant analyse regex
final rules = [
  SuggestionRule(
    kind: SuggestionKind.phone,

9. Animations, Courbes & Transitions Physiques

Les animations du web reposent sur Framer Motion avec des ressorts amortis (`Spring`). En Flutter, utilisez `SpringDescription` ou `AnimationController` avec courbes personnalisées.

9.1 Constantes de Ressort Source

1. Ressort Global de Navigation & Modales :
   - Web source : `stiffness: 380, damping: 34`
   - Équivalent Flutter :
     ```dart
     final navSpring = SpringDescription.withDampingRatio(
       mass: 1.0,
       stiffness: 380.0,
       ratio: 0.87, // Amortissement doux et rapide
     );
     ```
2. Rebond du Badge Numérique (Pulse) :
   - Web source : `stiffness: 500, damping: 15`
   - Sensation : rebond prononcé lors de l'incrémentation du nombre de pensées.
3. Coche de Validation (Checkmark) :
   - Web source : `stiffness: 600, damping: 20`
   - Sensation : pop vif et instantané.
4. Animation de la Pensée Déposée (« Flying Text ») :
   - Translation simultanée : `x: +140px`, `y: -260px`, `scale: 0.2`, `opacity: 0`.
   - Durée : `600ms`.
   - Courbe de Bézier : `Cubic(0.6, 0.0, 0.3, 1.0)`.
   - Point de pivot : coin supérieur droit (`Alignment.topRight`).
   - Séquence temporelle :
     - À $t = 0\text{ ms}$ : déclenchement du vol.
     - À $t = 450\text{ ms}$ : pulsation du badge du panier supérieur droit.
     - À $t = 900\text{ ms}$ : réinitialisation complète de l'état.

9.2 Transition d'Écran (Capture $\leftrightarrow$ Inbox)

- Entrée Inbox : glissement depuis la droite (`x: 100%` $\rightarrow$ `0%`).
- Sortie Capture : recul discret vers la gauche avec fondu (`x: -30%`, `opacity: 0`).

11. Incohérences Détectées dans le Code Source & Recommandations Flutter

Lors de l'analyse intégrale du code, voici les spécificités et légers écarts relevés :

1. Écart de teinte `theme-color` vs `background` :
   - `src/routes/__root.tsx` déclare `<meta name="theme-color" content="#f8f5f0">`.
   - `src/styles.css` déclare `--background: oklch(0.975 0.006 75)` dont la conversion exacte donne `#F9F6F2`.
   - Recommandation Flutter : Utilisez exclusivement `#F9F6F2` pour le `Scaffold.backgroundColor` et la teinte de la barre d'état système pour une parfaite harmonie.
2. Graisse de titre implicite :
   - La balise `<h1 className="font-serif text-[38px] leading-none tracking-[-0.02em]">` dans l'inbox ne définit pas de classe de graisse (`font-bold` ou `font-medium`), héritant ainsi de `font-normal` (400) par la réinitialisation moderne de Tailwind. En Flutter, spécifiez explicitement `fontWeight: FontWeight.w400` sur le `TextStyle` de `Newsreader`.
3. Contraste du texte sur le Toast :
   - Le Toast utilise `bg-foreground` avec `text-background`. En mode sombre, le texte devient donc le fond sombre et le toast devient blanc cassé, ce qui correspond au comportement dynamique inverse d'un Toast natif.
